# Big Booty Bass

**A free mono 808 bass synth by Ken Wheeler.**

20 original hip-hop, trap and drill presets. 24 sound controls shape both the bass and its reactive character artwork. Includes glide, pitch and amplitude envelopes, saturation, filtering and stereo width over a mono sub.

## [Download the Mac beta →](https://github.com/kenwheeler/big-booty-bass/releases/download/v0.1.0-beta.1/Big-Booty-Bass-Apple-Silicon-beta1.zip)

### Install

Save your work and close your DAW. Unzip the download. In Finder, use **Go → Go to Folder**, then copy the format you need:

- `Big Booty Bass.component` → `~/Library/Audio/Plug-Ins/Components`
- `Big Booty Bass.vst3` → `~/Library/Audio/Plug-Ins/VST3`

Create the folder if needed. Keep any previous bundles as backups. Reopen your DAW and rescan plugins if needed. Find **Big Booty Bass** under **Ken Wheeler Audio**. Load it onto a MIDI track.

### Play

Choose one of 20 presets with the arrows or preset list. Drag dials, hold Shift for finer adjustments, or double-click to reset. Select a dial and use arrow keys or Enter for numeric entry.

The latest artwork has smooth shaded skin, an ornamental tattoo and stronger note-driven hip movement. Each sound control changes its appearance. **Reduced motion** stops the movement without changing the sound. Artwork depicts a stylized adult in opaque underwear.

### Beta limits

- Apple Silicon only. No Intel or Windows build.
- Monophonic; pitch bend is fixed at ±2 semitones.
- 22 release tests, VST3 pluginval strictness 5, native AU rendering/state checks, and installed Apple auval pass on the development Mac.
- The previous build loaded in Ableton Live 11.3.43. This visual revision retains byte-identical 20-preset audio, but a fresh in-Live visual check remains pending.
- Broad DAW/macOS compatibility, clean downloaded installation and musical acceptance are not claimed.
